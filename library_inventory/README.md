# 图书库存管理系统

这是一个适合 Python 初学者的完整项目。我们会从命令行版本开始，再逐步升级到 SQLite 和图形界面。

## 当前版本

第一阶段：命令行菜单 + 添加图书 + 查看图书 + JSON 保存。

## 文件说明

- `main.py`：程序入口，负责显示菜单。
- `book.py`：图书类，负责描述一本书的数据结构。
- `manager.py`：图书管理功能。
- `storage.py`：读取和保存数据。
- `books.json`：图书数据文件。

## 运行方法

在 PyCharm 里运行 `main.py`。

也可以在终端运行：

```bash
python library_inventory/main.py
```

## 已完成功能

- 添加图书
- 查看所有图书
- 按书名搜索图书
- 修改库存
- 删除图书
- 借书
- 还书

## 下一步任务

实现 `low_stock_alert()`：

1. 读取所有图书。
2. 设置一个低库存标准，比如 `3`。
3. 遍历所有图书。
4. 如果某本书的 `available_stock` 小于低库存标准，就打印这本书的信息。
5. 如果没有任何低库存图书，提示“没有低库存图书”。

## 验收标准

- 库存小于 3 的图书会被列出来。
- 库存等于 3 的图书不会被列出来。
- 没有低库存图书时，会显示“没有低库存图书”。
- 这个功能只查看数据，不修改 `books.json`。
